# NOVA brand

The chosen direction is **Lumen N**, a stencil N whose diagonal is a separate beam of light passing between two stems. Light passes through the frame: that is what a player does.

Concept exploration: `concepts/` (A Corona, B Viewfinder, C Lumen N). Masters are generated by `build_brand.py` from explicit geometry, with no fonts and no live text. Run `python brand/build_brand.py` to rebuild them.

## Files (`final/`)

| File | Use |
| --- | --- |
| `nova-symbol.svg` / `-on-dark.svg` | Symbol in brand colours on light / dark backgrounds |
| `nova-symbol-small.svg` | Small-size cut (≤ 32 px): heavier stems, wider gaps |
| `nova-symbol-black.svg`, `-white.svg`, `-mono-171715.svg` | One-colour versions |
| `nova-app-icon.svg` / `.png` | App, taskbar and installer icon (ink tile; symbol at 70% of the tile) |
| `nova-wordmark.svg` / `-on-dark.svg` / `-black.svg` | Wordmark. Its N *is* the symbol, so the symbol is never placed next to the wordmark ("NNOVA") |
| `favicon.*`, `icon-*.png`, `site.webmanifest` | Web icon set |

App icons in `apps/desktop/src-tauri/icons/` are generated from `nova-app-icon.png` with `pnpm tauri icon`.

## Construction

The grid is 256 units, with a cap height of 176.
- **Stems:** 32 wide.
- **Beam:** 44 wide (measured horizontally), slope 48/176 (15.3° from vertical), with 10-unit stencil gaps on either side.
- **Small cut:** 40-wide stems, a 52-wide beam and 16-unit gaps.
- **Other letters:**
  - O is a 32-weight ring.
  - V and Λ are solid letters on the beam's slope with 34-wide strokes.
  - Only the N is stenciled; it is the one ownable glyph.

## Colour

| Name | HEX | RGB | Role |
| --- | --- | --- | --- |
| Ink | `#171715` | 23 23 21 | Stems, text, dark surfaces |
| Cream | `#F7F4EE` | 247 244 238 | Light surfaces, stems on dark |
| Ember | `#F97316` | 249 115 22 | The beam. In the UI it means "now": playhead, current item, focus |

Ember is a fill colour, not a text colour on cream: the contrast is about 2.8:1. On ink it is fine (about 6.4:1). One-colour versions must always remain possible; the beam is already separated by gaps.

## Usage

- **Clear space:** the width of one stem (32 units at master size) on every side.
- **Minimum size:** symbol 16 px (use the small cut ≤ 32 px); wordmark 64 px wide.
- **Approved backgrounds:** cream, white or ink; photos only behind the one-colour white or black version.
- **Don'ts:**
  - Don't recolour the stems orange or the beam any other colour.
  - Don't close the stencil gaps, add gradients, shadows or outlines, or rotate or stretch the mark.
  - Don't set "NOVA" in a font in place of the wordmark.
  - Don't put the symbol beside the wordmark.
