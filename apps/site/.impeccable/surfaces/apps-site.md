Scope: NOVA preview website (apps/site), all routes. Mode: Persuade (home, product, compare, release), Read (atlas, trust, docs).
Audience: Windows viewers first, media professionals one step deeper. Job: understand what NOVA is, see the real app, judge compatibility honestly, know it is a preview.
Proof: real captures of NOVA 0.1.0 playing CC-BY Blender films; compatibility harness results (55 synthetic samples, software + hardware passes); RC1 test record.
Constraints: no downloads, no installer, no "open source" as fact (licence undecided), no network claims beyond code evidence, no analytics, preview banner + noindex.

## Direction contract
THESIS: The site is NOVA's catalogue, projected. It refuses the dark-gradient hero with three feature cards and a Download button; evidence and the real app carry the page.
OWN-WORLD: Cream paper (#F7F4EE) and ink (#171715) stock, a darkroom (#0B0B0A) plate for the app itself, ember (#F97316) used once per view as the beam/playhead meaning "now". Archivo variable: condensed spine display (width 68-72%), normal-width text. Ink-stamp status marks, hairline seams, plate captions with catalogue numbers, the page seek bar.
STORY: Visitors learn NOVA is a calm, honest Windows player; see it working on real film; check their formats in the Atlas; leave knowing it is a preview and what is pending.
FIRST VIEWPORT: The full-width Lumen wordmark set at viewport scale on cream; the beam sweeps once through the N's gap and becomes the page seek bar at the top. FORM: Spine Catalog extension (established world; brief-pinned, no seed roll). Signature interaction: the Projector, a seek-bar tablist of real captures (arrow keys scrub chapters, ember playhead moves).
